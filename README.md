# Retail Sales & Customer Analytics Using Python

## IBM Data Analytics Internship Project

### Project Overview
This project demonstrates a complete data analytics workflow on a synthetic retail sales dataset. It covers data preparation, exploratory analysis, business metrics, visualization and actionable insights.

### Objective
- Analyze monthly revenue and profit trends
- Compare category performance
- Identify top-performing products
- Understand customer revenue contribution
- Study the relationship between quantity sold and profit
- Convert analysis into business recommendations

### Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter/VS Code
- CSV dataset

### Dataset
`retail_sales_data.csv` contains 1,200 synthetic sales records generated for this portfolio project. It includes date, customer, region, category, product, quantity, unit price, discount, revenue, cost and profit.

**Important:** The dataset is synthetic and is not claimed to represent IBM or any real company's confidential data.

### Project Workflow
1. Data collection/generation
2. Data cleaning
3. Exploratory Data Analysis (EDA)
4. KPI calculation
5. Visualization
6. Business insights
7. Recommendations

### Key KPIs
- Total Revenue
- Total Profit
- Profit Margin
- Number of Sales Records
- Unique Customers
- Category Revenue
- Product Revenue

### How to Run

```bash
pip install -r requirements.txt
python retail_sales_analysis.py
```

The script generates four charts inside the `outputs` folder.

### Business Insights
The analysis can be used to identify:
- Monthly periods with stronger/weaker revenue
- Categories contributing most to sales
- High-revenue products
- High-value customers
- The relationship between order quantity and profit

### Recommendations
1. Maintain inventory availability for high-revenue products.
2. Review low-performing categories and products before increasing stock.
3. Use customer-level revenue analysis for targeted offers.
4. Monitor discounts because excessive discounting can reduce profit margin.
5. Track monthly KPIs regularly to identify changes early.
